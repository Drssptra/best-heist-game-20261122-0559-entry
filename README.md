Midnight Vault — a top-down stealth heist game: sneak through a museum hall at night, dodge patrolling guards' vision cones and sweeping security cameras, manage the alarm meter, grab the golden idol and slip out the getaway door.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD or arrow keys (or click to walk), hold Shift to sneak, Q for a smoke pellet, E to loop the cameras.
